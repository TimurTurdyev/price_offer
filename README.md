# Price Offer

Коммерческое предложение для OpenCart 2.3, PHP 7.0+. Покупатель выбирает нужное предложение и скачивает xlsx с оптовыми ценами по категориям или просит прислать его на почту.

## Установка

1. Скопировать содержимое `upload/` в корень магазина.
2. Поставить [PhpSpreadsheet](https://github.com/PHPOffice/PhpSpreadsheet):

   ```bash
   composer install -d system/library/PhpSpreadsheet
   ```

3. Установить модуль "Коммерческое предложение" в списке модулей, при установке создается таблица `price_offer_exclude`.
4. Включить модуль в настройках и завести предложения.

Адрес страницы: `index.php?route=extension/module/price_offer`.

## Настройка

Предложения разложены по разделам и группам: у предложения свои категории и свои скидки. Новое предложение заводится так: отмечаем категории, выбираем, куда его поставить, пишем название и скидки. Стрелками их можно переставлять: ссылки на витрине привязаны к номеру предложения, а не к позиции.

Скидки в процентах идут в колонки "Мелкий опт", "Средний опт" и "Крупный опт". Если у товара заданы скидки за количество, в выгрузку попадают его скидки. Если у предложения скидка не указана, берется скидка группы "По умолчанию".

По "Товарам" видно, что попадет в предложение. Скидки товара пишутся как `10>5|50>10` (количество>процент) и сохраняются в обычные скидки для группы покупателей по умолчанию. Тут же товар можно исключить из выгрузки.

## Что в xlsx

Сверху реквизиты из настроек, контакты и логотип магазина, ниже название предложения и цены. Если у товара есть опции, под его названием перечислены значения опций с ценами. Неактивные и исключенные товары не попадают в выгрузку.

Имя задается в настройках, к нему дописывается дата. На почту предложение уходит не чаще раза в полминуты для одной сессии.
